# MehndiMagicAI

A Play Store style Android app concept for mehndi design inspiration and app discovery experience.

## What’s included
- Play Store-inspired home screen
- Trending / categories / top charts layout
- Elegant mehndi-themed app cards and install CTA
- Android app project ready for Android Studio

## Run in Android Studio
1. Open the project in Android Studio.
2. Wait for Gradle sync to finish.
3. Select a device or emulator.
4. Run the app.

## Install on a connected Android phone
If your phone is connected via USB and debugging is enabled:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
